# OBJ placement

Copy [example-cube.obj](example-cube.obj) into `ComfyUI/input/3d`, or upload it
through Load OBJ. Open [obj-placement.json](obj-placement.json), select the OBJ,
and click **Queue**. Empty Image supplies the background and Preview Image shows
the composite. Python rendering requires the optional 3D dependencies and a
working OpenGL context.
